# 点群ビューア (LAS / LAZ / COPC)

ブラウザだけで動作する点群ビューアです。サーバー不要・インストール不要で、
`dist/index.html` 1 ファイルをブラウザで開くだけで使えます。

## 主な機能

- **LAS / LAZ / COPC の読み込み**（ドラッグ＆ドロップ、ファイル選択、URL 指定）
- **大容量対応**
  - LAS（非圧縮）: 分割読み込み＋均等間引き。数 GB でもメモリを消費しない
  - COPC（`.copc.laz`）: オクツリー階層を辿り、表示点数上限に収まるレベルまでを読み込む
  - 通常の LAZ: laz-perf (WASM) で展開。ファイル全体をメモリに載せる必要があるため **1.5 GB まで**
- **色分け**: 標高（Turbo カラーマップ）/ RGB（8bit・16bit 自動判定）/ 反射強度 / 分類（ASPRS 標準色）
- **表示調整**: 点サイズ、距離減衰、標高レンジ、強度レンジ、RGB ガンマ、背景色
- **表示点数上限**: 1 ファイルあたりの上限（0.1M〜20M）。変更後「上限を適用して再読込」
- **距離計測**: 2 点クリックで 3D 距離・水平距離・高低差を表示
- **複数ファイル同時表示**: レイヤーごとに表示 ON/OFF、ズーム、削除
- **地図の重ね合わせ**: 座標系（平面直角座標系 I〜XIX / UTM / Web メルカトル）を指定し、
  国土地理院タイル（標準地図・淡色地図・全国最新写真）または OpenStreetMap、任意の XYZ タイルを地面に敷く
- **3D モデルの重ね合わせ**: glb / gltf / obj を実座標で配置（位置・倍率・方位角・Y-up/Z-up）
- **写真の重ね合わせ**: jpg / png を実座標で配置（位置・幅・方位角・傾き・不透明度）

## 使い方

```
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # dist/index.html を生成（単一ファイル、JS/WASM/Worker をすべて内包）
```

`dist/index.html` はそのままダブルクリックで開けます。社内 Web サーバーに置いても動きます。

### URL からの読み込み

`?url=https://.../file.copc.laz` を付けて開くと自動で読み込みます。
サーバー側は **Range リクエスト** と **CORS** (`Access-Control-Allow-Origin`) が必要です。
COPC + Range 対応サーバーの組み合わせなら、数 GB のファイルでも必要な部分だけを取得します。

### 大容量 LAZ の扱い

通常の LAZ は圧縮方式の都合で全体をメモリに載せる必要があります。1.5 GB を超えるものは
PDAL で COPC に変換してください（LAZ のまま、かつランダムアクセス可能になります）。

```
pdal translate in.laz out.copc.laz --writers.copc.forward=all
```

### 地図の重ね合わせ

1. 「地図の重ね合わせ」で点群の座標系を選ぶ（LAS に WKT があれば自動推定）
2. 点群の X が北・Y が東の並び（測量座標系そのまま）の場合は「X=北, Y=東」にチェック
3. 「地図を表示」。高さオフセットで地図面の高さ、不透明度で透過を調整

地理院タイルの利用は [国土地理院の利用規約](https://maps.gsi.go.jp/development/ichiran.html) に従ってください。

## トラブルシューティング

- **「Worker error」「Worker を起動できませんでした」**: HTML を Claude アプリ内のプレビューや一部のビューアで開くと、
  セキュリティ設定 (CSP) により Web Worker が禁止されることがあります。この場合は自動的にメインスレッドで
  読み込みますが（画面が一時的に固まります）、Chrome / Edge で HTML を直接開くことを推奨します。
- **「Worker が異常終了しました」**: ブラウザのメモリ不足の可能性があります。「表示点数上限」を下げて
  「上限を適用して再読込」してください。
- **ヘッダの点数が 0 / 過大なファイル**: ファイルサイズから点数を補正して読み込みます（ステータスに表示）。
- ファイルサイズの上限: LAS と COPC にはありません。通常の LAZ は 1.5 GB まで（上記 COPC 変換を参照）。

## 操作

| 操作 | 内容 |
|---|---|
| 左ドラッグ | 回転 |
| 右ドラッグ | 平行移動 |
| ホイール | ズーム |
| クリック | 座標表示（右下）。計測モード中は 2 点で距離計測 |
| ツールバー | 全体 / 真上 / 北から / 東から / 斜め / ウォークスルー |

### ウォークスルー（一人称）

ツールバーの「ウォークスルー」、または点群をクリックしてから「ウォークスルー」セクションの「クリック点から開始」で目線高さ（既定 1.6 m）に立ちます。

| キー | 動作 |
|---|---|
| W / ↑, S / ↓ | 前進 / 後退（水平方向） |
| A, D | 左 / 右移動 |
| ← / → | 左 / 右旋回 |
| Q / E | 上 / 下俯仰 |
| R / F | 上昇 / 下降 |
| Shift | 3 倍速 |
| 左ドラッグ / ホイール | 視線 / 前後移動 |
| Esc | 終了（軌道操作に戻る） |

移動速度・旋回速度はパネルで調整できます。

## 構成

```
src/
  main.ts            UI とアプリの組み立て
  ui.ts              DOM ヘルパー
  las/
    format.ts        LAS ヘッダ・点レコードのパーサ、COPC info VLR
    worker.ts        読み込み Worker（LAS 分割読込 / LAZ 展開 / COPC 階層読込）
    loader.ts        Worker のラッパー
    messages.ts      Worker メッセージ型
  viewer/
    Viewer.ts        three.js シーン、レイヤー管理、ピッキング、計測
    shaders.ts       点描画シェーダ（色分けモード・点サイズ）
    crs.ts           座標系定義（proj4）
    overlays.ts      地図タイル / 3D モデル / 写真の重ね合わせ
scripts/
  make_sample.py     テスト用 LAS/LAZ の生成（laspy + lazrs）
```

### 設計メモ

- 座標は「最初に読んだファイルの min」を原点とする相対座標 (float32) で GPU に送り、
  平面直角座標のような大きな値でも精度落ちしないようにしています。実座標は double で保持。
- 点の色分けはすべて GPU (シェーダ) で行うため、モード切替で再読込は不要です。
- Worker は 1 ファイル 1 個。複数ファイルは並列に読み込みます。
- 対応点フォーマット: PDRF 0〜10（RGB は 2, 3, 5, 7, 8, 10）。

## 動作確認済み

- 合成 LAS 2M 点 (68 MB) / LAZ 2M 点 (25 MB) / 合成 LAS 30M 点 (1.02 GB → 3M 点表示、約 3 秒)
- Autzen COPC (10.6M 点, 81 MB) → 上限 3M で 2.9M 点表示

## 依存

three.js, laz-perf (WASM), proj4, Vite, TypeScript
