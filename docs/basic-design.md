# 点群ビューア 基本設計書

## 1. 文書の位置付け

本書は本システムの**基本設計**（システム全体の目的・構成・機能・非機能要件・外部インターフェース）を
定義する。モジュール内部の処理詳細・データ構造・シーケンスは
[docs/detailed-design.md](detailed-design.md)（詳細設計書）を参照。
利用者向けの操作手順・ビルド手順は [README.md](../README.md) を参照。
開発時の作業工程は [CONTRIBUTING.md](../CONTRIBUTING.md) を参照。

## 2. システム概要

### 2.1 目的

測量・建設・地形解析等で得られる LAS / LAZ / COPC 形式の点群データを、
サーバーやインストール作業なしに、ブラウザだけで閲覧・計測・地図/3Dモデル/写真との
重ね合わせ確認ができるようにする。

### 2.2 対象ユーザー

- 点群データを取得した測量・建設・地理空間の担当者
- 大容量点群を手軽に共有・確認したい社内外の関係者（`dist/index.html` 1 ファイルの配布のみで動作）

### 2.3 動作環境

| 項目 | 内容 |
|---|---|
| 実行環境 | モダンブラウザ（Chrome / Edge 推奨。WebGL 対応が必須） |
| サーバー | 不要（静的ファイルとして配布、`file://` でも起動可能） |
| 配布形態 | `npm run build` で生成される単一 HTML（JS/WASM/Worker を内包） |
| ネットワーク | 任意。URL指定読込・地図タイル表示時のみ通信を使用 |
| Web公開 | GitHub Pagesで公開する場合は **GitHub Actionsでビルドし`gh-pages`ブランチ等へデプロイする方式**を採る。<br>`main`ブランチの`/docs`をPages公開元にする方式は、設計書格納先の`docs/`（本書等）と衝突するため採用しない。 |

## 3. システム構成

### 3.1 全体構成図

```mermaid
flowchart TB
    subgraph Browser[ブラウザ]
        UI[UI層 main.ts / ui.ts]
        Loader[読込制御 las/loader.ts]
        Worker[Web Worker las/worker.ts]
        Decode[デコード処理 las/decode.ts + format.ts]
        Wasm[laz-perf (WASM)]
        Viewer[3D描画 viewer/Viewer.ts + shaders.ts]
        Overlay[重ね合わせ viewer/overlays.ts]
        Crs[座標変換 viewer/crs.ts (proj4)]
    end
    subgraph External[外部リソース（任意）]
        File[ローカルファイル / URL(Range対応サーバー)]
        Tile[地図タイル配信\n(地理院/OSM/カスタムXYZ)]
    end

    File --> Loader
    UI --> Loader
    Loader --> Worker --> Decode --> Wasm
    Decode --> UI
    UI --> Viewer
    Viewer --> Overlay
    Overlay --> Crs
    Overlay --> Tile
```

### 3.2 技術スタック（概要）

| 区分 | 採用技術 | 採用理由 |
|---|---|---|
| 3D描画 | three.js | WebGLの抽象化、カスタムシェーダ拡張が容易 |
| 点群圧縮展開 | laz-perf (WASM版LASzip) | ブラウザのみでLAZ展開が可能 |
| 座標変換 | proj4 | 平面直角座標系・UTM・Webメルカトル等の相互変換 |
| ビルド | Vite + vite-plugin-singlefile | 単一HTML配布を実現 |
| 型検査 | TypeScript | ビルド時の型チェック（`tsc --noEmit`） |

詳細なモジュール構成・処理フローは [詳細設計書 2章・3章](detailed-design.md#2-システム概要) を参照。

## 4. 機能一覧

| # | 機能 | 概要 |
|---|---|---|
| F1 | 点群読み込み | LAS/LAZ/COPCをドラッグ&ドロップ・ファイル選択・URL指定で読み込む |
| F2 | 大容量対応読み込み | LAS分割読込＋間引き、COPC階層選択読込、LAZ全展開（1.5GBまで） |
| F3 | 色分け表示 | 標高（Turbo）／RGB／反射強度／分類（ASPRS標準色） |
| F4 | 表示調整 | 点サイズ、距離減衰、標高/強度レンジ、RGBガンマ、背景色 |
| F5 | 表示点数上限設定 | ファイル毎に0.1M〜20Mの上限を設定し再読込 |
| F6 | 距離計測 | 2点クリックで3D距離・水平距離・高低差を表示 |
| F7 | 複数ファイル表示 | レイヤー単位の表示ON/OFF・ズーム・削除 |
| F8 | 地図重ね合わせ | 座標系指定＋地理院/OSM/カスタムXYZタイルを地面に敷く |
| F9 | 3Dモデル重ね合わせ | glb/gltf/objを実座標に配置（位置・倍率・方位角・Y-up/Z-up） |
| F10 | 写真重ね合わせ | jpg/pngを実座標に配置（位置・幅・方位角・傾き・不透明度） |
| F11 | 視点操作 | 軌道操作（回転/平行移動/ズーム）、定型視点（真上/北/東/斜め）、ウォークスルー（一人称） |

各機能の内部処理詳細は [詳細設計書 3章](detailed-design.md#3-モジュール詳細設計) の対応モジュールを参照。

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| 性能 | 表示点数上限（既定300万点）で快適な操作感を維持。大容量ファイルはWorkerで非同期処理しUIブロッキングを回避 |
| ファイルサイズ | LAS/COPCは上限なし（分割/階層読込）。通常LAZは1.5GBまで（WASM全展開の制約） |
| 精度 | 原点相対座標＋float32でGPU転送し、大きな絶対座標（平面直角座標系等）でも精度劣化を防止 |
| 可用性 | Worker起動不可（CSP制限等）の環境ではメインスレッド処理に自動フォールバック |
| 可搬性 | ビルド成果物は単一HTMLファイルで、サーバー・インストール不要 |
| セキュリティ | 外部通信は「URL指定読込」「地図タイル取得」時のみ。地図タイルはCORS/利用規約に従う |

## 6. 画面設計（概要）

### 6.1 画面構成

```
┌─────────────┬───────────────────────────────┐
│ 左パネル      │ 3Dビュー(canvas)                │
│ (#panel)     │ - ツールバー（視点切替）           │
│ ・ファイル     │ - ステータス表示（左下）           │
│ ・表示        │ - 座標表示（右下）                │
│ ・ウォークスルー │ - ドロップオーバーレイ            │
│ ・距離計測     │                                 │
│ ・地図重ね合わせ │                                 │
│ ・3Dモデル     │                                 │
│ ・写真        │                                 │
│ ・操作方法     │                                 │
└─────────────┴───────────────────────────────┘
```

左パネルは折りたたみ可能なセクション（`<details>`）で構成し、機能ごとに独立して操作できる。
UI部品はフレームワークを使わず `src/ui.ts` の小関数群（`el`/`slider`/`select`/`button`等）で組み立てる。

### 6.2 主要な操作

| 操作 | 内容 |
|---|---|
| 左ドラッグ | 回転 |
| 右ドラッグ | 平行移動 |
| ホイール | ズーム |
| クリック | 座標表示／計測モード中は2点で距離計測 |
| ツールバー | 全体／真上／北から／東から／斜め／ウォークスルー |

ウォークスルー中のキー操作等、詳細は [README.md「操作」](../README.md#操作) を参照。

## 7. データ設計（概要）

### 7.1 対応フォーマット

| 形式 | 読み込み方式 | サイズ上限 |
|---|---|---|
| LAS（非圧縮） | 分割読込＋均等間引き | なし |
| COPC（`.copc.laz`） | オクツリー階層読込（点数予算内のレベルまで） | なし |
| 通常LAZ | laz-perf(WASM)で全展開 | 1.5GB |

対応点フォーマット: PDRF 0〜10（RGBはPDRF 2, 3, 5, 7, 8, 10のみ）。

### 7.2 座標系

- 点群のGPU描画座標は「最初に読み込んだファイルのmin」を原点とした相対座標（float32）。
- 実座標はdouble精度で`Viewer.origin`に保持し、地図/モデル/写真配置時に変換する。
- 地図重ね合わせ時は、LASのWKT（VLR）から座標系を自動推定するか、`viewer/crs.ts`で定義した
  平面直角座標系（I〜XIX系）／UTM／Webメルカトルから選択する。

詳細なヘッダ構造・バイナリオフセット・座標変換式は
[詳細設計書 3.1節](detailed-design.md#31-lasformatts--lasヘッダ点データの解析) および
[3.9節](detailed-design.md#39-viewercrsts--座標系定義) を参照。

## 8. 外部インターフェース

| インターフェース | 内容 |
|---|---|
| URLパラメータ `?url=` | 起動時に指定URLの点群を自動読込（Range対応サーバー前提） |
| Range リクエスト | 大容量ファイルの部分読込（HTTP `Range`ヘッダ、CORS必須） |
| 地図タイルAPI | 地理院タイル（標準/淡色/写真）、OpenStreetMap、任意のXYZタイルURL |
| ローカルファイル入力 | `<input type=file>` / ドラッグ&ドロップによるLAS/LAZ/COPC/glb/gltf/obj/画像の読込 |

## 9. エラー処理方針（概要）

利用者に影響する主なエラーケースと対処方針。詳細は
[詳細設計書 5章](detailed-design.md#5-エラーハンドリング方針) を参照。

| ケース | 対処 |
|---|---|
| Workerが起動できない環境 | メインスレッド処理に自動フォールバック（画面通知） |
| Workerがメモリ不足で異常終了 | エラー表示し、表示点数上限を下げて再読込を案内 |
| 通常LAZが1.5GB超 | 事前にエラー表示し、COPCへの変換コマンドを案内 |
| Range非対応サーバーのURL指定 | 読込前にエラー表示 |

## 10. 制約・前提事項

- WebGL対応ブラウザが前提（非対応環境は動作不可）。
- 地図タイルの利用は各提供元の利用規約に従う（例: 国土地理院タイル）。
- 大容量点群の精度・表示点数はトレードオフの関係にあり、間引きは均等ストライド方式（密度ベース最適化は行わない）。
